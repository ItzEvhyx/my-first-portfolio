## Quick Start

1. Click **Use this template** at the top of this repository, then **Create a new repository**.
2. Clone your new repository:
   ```bash
   git clone [your-repo-url]
   cd [your-repo-name]
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
6. Edit the files, save, and watch the page update automatically.

## Folder Structure

```
[repo-name]/
├── app/
│   ├── layout.jsx          # Page wrapper (you don't need to touch this)
│   ├── page.jsx            # Puts all the sections together
│   ├── globals.css         # Global styles
│   └── components/
│       ├── Header.jsx              # Navigation bar
│       ├── Intro.jsx               # Name, role, tagline
│       ├── AboutMe.jsx             # About you
│       ├── Skills.jsx              # Your skills
│       ├── Projects.jsx            # Your projects
│       ├── EducationExperience.jsx # Education and experience
│       ├── Contact.jsx             # Contact and social links
│       └── Footer.jsx              # Footer
├── public/
│   ├── assets/             # Fonts, icons, and your resume
│   ├── images/             # Your photo and project images
│   └── js/
│       └── script.js       # Optional vanilla JavaScript
├── package.json
└── README.md
```

## Deploy with Vercel

1. Push your repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import your repository.
3. Leave the default settings (Vercel detects Next.js automatically).
4. Click **Deploy**.
5. After about a minute, you'll get a live link like `[your-project].vercel.app`.
